# SIGNAL 🧠

## Less Noise. More Signal.

> An AI attention filter that helps information-overloaded college students decide what actually deserves their attention.

---

## 🚀 Overview

Students today are surrounded by assignments, deadlines, internships, hackathons, notifications, social media, tutorials, newsletters, and endless new information.

The problem isn't a lack of information.

**It's deciding what deserves attention.**

SIGNAL sits between information and attention. It analyzes competing inputs using the user's goals, deadlines, workload, attention budget, relevance, urgency, impact, effort, reliability, and opportunity cost.

It then converts information overload into:

**NOW → NEXT → LATER → IGNORE**

SIGNAL helps answer one question:

## 🧠 AI & Prompt Engineering

SIGNAL was developed through iterative prompt engineering rather than relying on one generic prompt.

### V1 — Basic Classification
Started with simple prioritization.  
*Problem:* Too generic and lacked user context.

### V2 — Context-Aware Filtering
Added:
- User goals
- Deadlines
- Workload
- Attention budget
- Impact
- Effort

### V3 — Decision Engine
Added:
- Opportunity cost
- FOMO detection
- Reliability
- Confidence
- Dynamic priority
- Duplicate detection

### V4 — Evaluation Loop
Added:
- Test scenarios
- Expected behavior
- Failure cases
- Human override
- User feedback
- Quality evaluation

*This transformed SIGNAL from a basic classifier into a context-aware attention decision system.*

---

## 🧩 Core Prompt Architecture

SIGNAL's AI behavior is structured around:

1. **Role**
2. **Context**
3. **Goals**
4. **Constraints**
5. **Evaluation Criteria**
6. **Decision Framework**
7. **Output Contract**

Core decision categories:
- **NOW**
- **NEXT**
- **LATER**
- **IGNORE**

The system is instructed not to invent missing information, confuse popularity with importance, or pretend certainty when context is insufficient.

---

## ⭐ Key Features

- **Signal Engine**: Turns multiple information inputs into actionable priorities.
- **NOW / NEXT / LATER / IGNORE**: Converts information overload into a clear decision.
- **Attention Budget**: Treats attention as a limited resource.
- **Decision Mode**: Explains why something deserves attention.
- **FOMO Detection**: Helps prevent trend-driven decisions.
- **Opportunity-Cost Reasoning**: Considers what pursuing one opportunity means giving up.
- **Human Override**: The student remains in control of the final decision.
- **Signal Lab**: Shows how the AI system and prompts were designed and evaluated.
- **Judge Mode**: Provides a fast competition-ready demonstration.
- **Story Mode**: Explains the problem and solution visually.

## 🎬 Example

A student receives:
1. DBMS assignment → due tomorrow
2. Hackathon → registration closes tonight
3. Internship → deadline in 5 days
4. New AI course
5. React tutorial
6. LinkedIn post
7. AI newsletter
8. Trending AI framework

SIGNAL evaluates the information against the student's current context.

**The result becomes:**

- **NOW**
  - → Hackathon registration
  - → DBMS assignment
- **NEXT**
  - → Internship application
- **LATER**
  - → Useful course/tutorial
- **IGNORE**
  - → Generic newsletter
  - → Trend-driven content
  - → Irrelevant posts

*The goal isn't to process everything. It's to know what deserves attention.*

---

## 🛡️ Responsible AI

SIGNAL is designed to assist judgment, not replace it.

The system supports:
- Human override
- Confidence indicators
- Missing-context handling
- No invented deadlines
- Feedback-based personalization
- Transparent decision factors

*SIGNAL does not claim perfect or objectively correct decisions.*

---

## ⚠️ Limitations

SIGNAL's recommendations depend on the quality and completeness of the information provided.

Ambiguous goals, missing deadlines, conflicting priorities, or misunderstood context can lead to uncertain recommendations.

Therefore:
> **SIGNAL recommends. The human decides.**
